# API Gateway routes

Generated by `backend/scripts/generate-gateway-docs.js` from `backend/shared/serviceCatalog.js`. All clients call the gateway (`https://api.bookmyvilla.online`, locally `http://localhost:2001`); services are never called directly, and `/internal/*` paths are never routed by the gateway.

| Service | Internal port | Type | Responsibility | Public paths |
|---|---|---|---|---|
| auth-service | 2101 | legacy-shared | Login, registration, mobile OTP, JWT, owner password setup | `/api/auth`, `/api/v1/auth` |
| user-service | 2102 | legacy-shared | Admin console, owners, customers, staff accounts, partner applications | `/api/admin-console`, `/api/admin`, `/api/partner`, `/api/v1/users` |
| villa-service | 2103 | legacy-shared | Villas, listings, data-entry onboarding, villa-manager and on-site operations | `/api/properties`, `/api/v1/villas`, `/api/villa-manager`, `/api/owner-ops`, `/api/caretaker`, `/api/caretaker-tasks`, `/api/guest-requirements`, `/api/inventory`, `/api/tourist-register` |
| booking-service | 2104 | legacy-shared | Booking holds, checkout, confirmation, cancellations, guest stays, owner finance | `/api/bookings`, `/api/customer-booking`, `/api/stay`, `/api/owner-finance`, `/api/v1/bookings` |
| availability-service | 2105 | legacy-shared | Rooms/units, calendars, date blocks and availability checks | `/api/owner-pms`, `/api/v1/availability` |
| pricing-service | 2106 | legacy-shared | Quotations, pricing rules and the sales desk | `/api/owner-quotes`, `/api/public/quotes`, `/api/owner-crm`, `/api/v1/pricing` |
| payment-service | 2107 | independent (own DB `PAYMENT_*`) | Payment orders, provider verification and payment records | `/api/v1/payments` |
| notification-service | 2108 | independent (own DB `NOTIFICATION_*`) | Consumes booking/payment events and records guest/owner notifications | `/api/notifications`, `/api/v1/notifications` |
| search-service | 2109 | independent (own DB `SEARCH_*`) | Public villa search with location, guests and date availability | `/api/search`, `/api/v1/search` |
| review-service | 2110 | independent (own DB `REVIEW_*`) | Guest ratings and reviews | `/api/feedback`, `/api/v1/reviews` |
| coupon-service | 2111 | independent (own DB `COUPON_*`) | Promotions, promo codes and add-ons | `/api/owner-catalog`, `/api/v1/coupons` |
| media-service | 2112 | legacy-shared | Property photos/videos and site hero images | `/api/properties/media`, `/api/site-heroes`, `/api/v1/media` |

Special rules (checked before prefixes): `POST ^/api/customer-booking/holds/[^/]+/verify/?$` → payment-service; `POST ^/api/v1/bookings/holds/[^/]+/verify/?$` → payment-service.

Every legacy path keeps working unchanged. `/api/v1/<domain>` aliases are the stable versioned entry points for new clients.

Gateway endpoints: `GET /health` (gateway process), `GET /ready` and `GET /api/health` (critical services ready — used by the deploy check), `GET /metrics`.
