# Docker

- `backend/Dockerfile` — one image for the API Gateway and all 12 services (the container command picks the process).
- `backend/services/<name>/Dockerfile`, `backend/api-gateway/Dockerfile` — per-service images (build context `backend/`).
- `<app>/Dockerfile` — development containers (Vite dev server); `<app>/Dockerfile.prod` — production static builds served by nginx on 8080.
- `docker-compose.yaml` is generated by `infrastructure/scripts/generate-compose.js`.
