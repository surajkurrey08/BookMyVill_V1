# Bundled font assets

These fonts support the existing BookMyVilla typography and icon families without requiring a CDN at runtime.

- google-fonts.css: Google Fonts CSS for Outfit 400, 500, 600, 700 and Playfair Display 700, obtained from https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700&family=Playfair+Display:wght@700&display=swap on 2026-10-04. font-0.ttf through font-4.ttf follow the stylesheet declaration order. Fonts are licensed under the SIL Open Font License.
- fa-solid-900.woff2 and fa-brands-400.woff2: Font Awesome Free 6.4.0, https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/webfonts/. Font license: SIL OFL 1.1.
- font-awesome.css: Font Awesome Free 6.4.0 CSS from https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css. Original copyright and license header retained; font-face declarations replaced with the two bundled WOFF2 sources. CSS license: MIT.

Only the existing families used by the site are bundled. Source URLs and licenses: https://github.com/Outfitio/Outfit-Fonts, https://github.com/googlefonts/Playfair, https://fontawesome.com/license/free.
